# Игра в слова — Telegram-бот (aiogram 3 + OpenAI)

## Что это

Telegram-бот для игры в слова с ИИ:
1. Игрок пишет слово.
2. Бот проверяет: только кириллица → совпадение с нужной буквой → слово не повторялось → существует ли слово (через OpenAI).
3. Бот вычисляет букву для следующего слова (если последняя буква ь/ы/ъ — берётся буква перед ней).
4. ИИ (OpenAI) придумывает своё слово на эту букву и отправляет игроку.
5. Цикл повторяется, пока кто-то не зайдёт в тупик (нет слов на нужную букву).

## Установка

1. Получите токен бота у [@BotFather](https://t.me/BotFather): команда `/newbot`.
2. Получите бесплатный API-ключ Groq на https://console.groq.com/keys (регистрация без карты, есть бесплатный лимит запросов).
3. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
4. Скопируйте `.env.example` в `.env` и заполните своими значениями:
   ```
   cp .env.example .env
   ```
5. Запустите бота:
   ```
   python main.py
   ```

> Бот использует Groq (OpenAI-совместимый API) с моделью `llama-3.3-70b-versatile` — она бесплатна для использования в рамках лимитов Groq.

## Структура проекта

- `main.py` — точка входа, запуск polling.
- `config.py` — загрузка токенов из `.env`.
- `handlers.py` — вся игровая логика и обработчики сообщений/кнопок.
- `states.py` — состояния FSM (ждём первое слово / ждём слово-продолжение).
- `keyboards.py` — инлайн-кнопки («Играть», «Ошибка ИИ», «Играть заново»).
- `word_utils.py` — проверка кириллицы и вычисление буквы для следующего слова.
- `openai_service.py` — запросы к OpenAI: проверка существования слова и генерация следующего.

## Кнопки в боте

- **Играть** — начинает новую игру, бот просит первое слово.
- **Ошибка ИИ** — нажимается, если бот придумал несуществующее слово или ошибся; сейчас просто показывает уведомление, но в `cb_report_error` (handlers.py) можно дописать логирование в файл/БД.
- **Играть заново** — сбрасывает игру и начинает с начала.

## Что можно улучшить дальше

- Хранить статистику побед/использованных слов в БД (sqlite/postgres) вместо памяти (MemoryStorage сбрасывается при перезапуске).
- Добавить таймер на ход.
- Сделать словарную проверку быстрее/дешевле — кэшировать уже проверенные слова, чтобы не дёргать OpenAI повторно на одни и те же слова.
- Ограничить минимальную длину слова, чтобы избежать совсем простых однобуквенных вариантов.
